# 🧮 Calculadora Interativa

Uma aplicação de calculadora desenvolvida com o objetivo de praticar lógica de programação, manipulação do DOM e estilização responsiva para a web.

---

## 🚀 Tecnologias Utilizadas
- **HTML5** (Estrutura da interface e dos botões)
- **CSS3** (Estilização, layout e design moderno)
- **JavaScript** (Lógica das operações matemáticas e interatividade)

---

## 📌 Funcionalidades
- [x] Operações matemáticas básicas (adição, subtração, multiplicação e divisão).
- [x] Botão de limpar visor (`C`).
- [x] Interface intuitiva e responsiva.
- [x] Tratamento básico para evitar erros de cálculo (como divisão por zero).

---

## 🎯 O que eu pratiquei neste projeto?
Desenvolver esta calculadora me ajudou a treinar conceitos essenciais de Front-end:
1. **Captura de eventos:** Como escutar cliques nos botões da interface usando JavaScript.
2. **Manipulação de estado:** Como guardar e atualizar os números digitados e a operação selecionada no visor.
3. **Lógica condicional:** Como estruturar as regras matemáticas e garantir que o resultado seja exibido corretamente.
